# Pong Game 🏓

A browser-based recreation of the classic arcade game Pong, built from scratch using HTML5 Canvas and vanilla JavaScript as part of a self-directed web development and game programming curriculum.

## Features

- 🎮 Touch controls for mobile play
- 🤖 AI-controlled opponent paddle
- ⚡ Real-time ball physics with collision detection
- 📊 Live score tracking
- 🔁 Game loop with proper state management

## Tech Used

- HTML5
- CSS3
- JavaScript (Canvas API)

## How to Play

1. Clone this repository
2. Open `index.html` in your browser
3. Use touch/drag controls (or arrow keys on desktop) to move your paddle
4. First to reach the winning score wins!

## What I Learned

Building this project helped me understand:
- Canvas rendering and animation loops
- Collision detection logic
- Managing game state (score, ball position, paddle position)
- Handling both touch and keyboard input
